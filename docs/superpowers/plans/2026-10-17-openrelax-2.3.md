# OpenRelax 2.3.0 (Reconcile) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the unpublished 2.2.x features (archived on `archive/local-2.2.1`) onto the hardened `origin/main` ("2.1 Preview") and ship the single line as 2.3.0.

**Architecture:** `origin/main` is the base; its safety model (`lib/OpenRelax.Core.ps1`, fail-closed settings, `Assert-CleanupPath`, opt-in defaults, protected Fotokapan ACLs, no argument recording by default) is never weakened. 2.2 features are re-implemented on top of it. Pure engine logic moves to `lib/OpenRelax.Engine.ps1` and pure Fotokapan read/diagnosis logic to `lib/OpenRelax.Trap.ps1`. Both are dot-sourced by `openrelax.ps1` and serialized into worker runspaces the way `$script:EngineCode` already does.

**Tech Stack:** Windows PowerShell 5.1, WinForms, Task Scheduler. Tests are plain PowerShell scripts in `tests/` (no Pester), run by `tests/verify.ps1` and `.github/workflows/verify.yml`.

**Spec:** `docs/superpowers/specs/2026-10-17-openrelax-roadmap-design.md` (section "2.3.0").

**Source of ported code:** branch `archive/local-2.2.1` (read with `git show archive/local-2.2.1:<path>`). Line references below of the form `2.2.1:openrelax.ps1:NNN` point into that branch.

## Global Constraints

- Every script runs on Windows PowerShell 5.1. Do not use PowerShell 7-only syntax (`??`, `?.`, ternary, `&&`).
- `.ps1` files keep their existing encoding: UTF-8 with BOM where the file already has one. New `lib/*.ps1` and `tests/*.ps1` are UTF-8 with BOM.
- Ported functions must run under `Set-StrictMode -Version 2`, since the tests use it. Read optional record fields through `$obj.PSObject.Properties['x']`, never as bare `$obj.x`.
- Default settings stay safe:
  - `recycle`, `wu`, `wer`, `gpusetup`, `shader` and `devcache` are off.
  - `trimRam`, `clearDns` and `trapRecordCommandLines` are off.
- Headless `-AutoClean` never runs `recycle`, `wu`, `wer`, `gpusetup`, `shader` or `devcache`.
- `Protect-CommandLine` returns `''` unless command-line recording was explicitly enabled at install time.
- Unattributed CPU is never called a driver. Culprit `*unattributed*` and legacy records' `*drivers*` map to category `unattributed`.
- Version string `2.3.0`, `AppEdition` `''`. No LTS claim.
- Never run a destructive test against a real profile. Engine tests delete only inside `New-TestWorkspace` fixtures.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Interfaces:**
- Produces:

```powershell
Invoke-JunkWalk -Root <string> [-ApprovedRoot <string>] [-Cutoff <datetime>] [-Remove]
                [-KeepDirectories] [-BudgetMs <int>] [-ByTopFolder]
# returns @{ Size=[long]; Count=[long]; Dirs=[long]; Partial=[bool]; Folders=@{<top>=[long]};
#            Skipped=[int]; ErrorCount=[int]; Errors=[string[]] (max 10) }
```

**Walker behaviour:**
- **Starting a remove walk:** a `-Remove` walk first calls `Assert-CleanupPath $Root $ApprovedRoot`; a missing `-ApprovedRoot` throws. A read-only walk only calls `Assert-NoReparseAncestors $Root`.
- **Enumeration:** stack walk with `DirectoryInfo.GetFileSystemInfos()`, as in `2.2.1:openrelax.ps1:561-626`.
- **Reparse points:** entries with `ReparsePoint` are never entered or deleted and add `Skipped++`.
- **Root containment:** every entry must satisfy `Test-PathWithin $entry.FullName $Root`; otherwise it is an error and the walk stops.
- **Before deleting files in a directory:** re-check that the directory and every parent up to `$Root` are not reparse points, using `[IO.File]::GetAttributes`. Do not walk ancestors above `$Root`; they were checked once at start.
- **Per file before delete:** call `$e.Refresh()` and skip if it became a reparse point or `LastWriteTime -ge $Cutoff`. Locked files add `Skipped++`.
- **Unreadable directories:** `ErrorCount++` and the message goes into `Errors`.
- **Directory removal:** after the walk, emptied directories are removed deepest first, unless `-KeepDirectories`.
- **Progress:** `$Sync.Beat`, `$Sync.Step`, `$Sync.CleanDone` and `$Sync.CleanBytes` advance by elapsed time, every 250 ms (as in 2.2.1).
- **Budget:** checked per directory and every 2048 entries.

`Measure-JunkPaths` and `Remove-JunkPaths` keep their origin signatures and result shapes (`openrelax.ps1:514-590`) but call `Invoke-JunkWalk`:
- `Remove-JunkPaths` passes `-ApprovedRoot $target.ApprovedRoot -Remove`, and `-KeepDirectories` when `MinAgeHours` is set (the origin staging rule).
- `Get-SafeTreeEntries` stays in Core for the test workspace and the installer.
