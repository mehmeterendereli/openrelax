# OpenRelax 2.4.0 (Embedded Fotokapan, footprint, distribution) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fotokapan runs inside OpenRelax (no admin, no SYSTEM task, one switch). The app's own load is measured and published. OpenRelax installs with one command from a verified release zip.

**Architecture:**
- **Sampler library.** Pure sampling and spike logic lives in a new `lib/OpenRelax.Sampler.ps1`, built on PDH (`PerformanceCounterCategory('Process').ReadCategory()`: ~16 ms CPU per read, sees protected processes without admin).
- **Background runspace.** `openrelax.ps1` runs the loop in its own runspace while the app is open. It writes the same JSONL/heartbeat contract to `%APPDATA%\OpenRelax\Fotokapan\`, so the existing reader/diagnosis/report/notification code in `lib/OpenRelax.Trap.ps1` keeps working.
- **Legacy trap.** The old SYSTEM task is only detected and offered for removal; its `ProgramData` records are still read.

**Tech Stack:** Windows PowerShell 5.1, WinForms, PDH performance counters, CIM, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-17-openrelax-ai-growth-design.md` (§3.1, §3.2, §4.1 distribution, §5 row 2.4).

## Global Constraints

- **Language and encoding.** Windows PowerShell 5.1 only. UTF-8 with BOM for `.ps1`. Every new function is safe under `Set-StrictMode -Version 2`.
- **Sampler privileges and load.** The sampler needs no administrator rights. When calm it reads only `Processor(_Total)` `% Processor Time`, `% DPC Time` and `% Interrupt Time` every 2 s. A process snapshot is taken only during a spike.
- **Record contract.** Records keep the existing contract: `monitor`, `start`, `ongoing` and `end`; `top[]` with `name, pid, pct, parent, scheduled, cmd, parentCmd`; `defender`. Two new fields are added: `dpc` and `interrupt` (percent of total CPU).
- **Measured driver load.** It becomes the culprit `*dpc*` (category `drivers`) only when `dpc + interrupt` is at least the top process share and at least 10 %. Legacy `*drivers*` and residual CPU stay `unattributed`.
- **Settings.**
  - `trapEnabled` is optional; the default is **true**.
  - `trapRecordCommandLines` now applies live, without a reinstall.
- **Opt-in behaviour.** Command lines stay opt-in and masked by `Protect-CommandLine`. Default settings stay safe; nothing destructive is added.
- **TestMode.** The sampler writes only to the fixture trap folder (`OPENRELAX_TRAP_DIR`). It never reads or writes `%APPDATA%` or `ProgramData`.
- **Commits.** Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The maintainer's PC.** A legacy SYSTEM task is installed and its records live in `ProgramData\…\logs`. The app must show that history, show "legacy task present" with a remove button, and not record each spike twice. While the legacy task runs, the embedded sampler stays off and says why.
2. **Toggling off while a spike is open.** The sampler stops within 3 s and writes an `end` or `monitor` record; the episode is cut, not left open forever.
3. **Closing the app.** The form closes without waiting more than 3 s for the sampler, and no runspace is left behind (exit-smoke).
4. **PDH instance names change** (`chrome#3`) when processes exit between two reads. Matching is by PID, never by instance name.
5. **A tampered or partial release zip.** `install.ps1` refuses it before extracting anything.

### Task 1: Sampler library (pure)

**Files:**

- Move `Protect-CommandLine` and `Test-ScheduledParent` here; `fotokapan.ps1` keeps its own copies until 2.5.

**Interfaces (Produces):**

```powershell
Read-ProcessCpuSample                      # -> @{ At=[datetime]; ByPid=@{ <pid>=@{ Instance=[string]; Raw=[long]; Ts=[long] } } }
Measure-ProcessCpu $Before $After [int]$CpuCount   # -> [object[]] @{ Pid; Instance; Pct } sorted by Pct desc, _Total/Idle excluded, matched by PID
New-SpikeTracker [int]$Threshold [int]$SustainSec [int]$IntervalSec   # -> state hashtable
Step-SpikeTracker $State [double]$Cpu [datetime]$Now   # -> '' | 'arm' | 'start' | 'ongoing' | 'end'
New-SpikeRecord [string]$Kind [datetime]$Start [double]$WindowSec [double]$Total $Rows $Processes [double]$Dpc [double]$Interrupt
                                           # -> [ordered] record (top 5)
Add-TrapRecord [string]$Dir $Record        # append one JSONL line, UTF-8 without BOM, file spikes-yyyy-MM.jsonl
Set-TrapHeartbeat [string]$Dir $State      # durum.json, atomic replace
```

**Tracker rules** (from `fotokapan.ps1`'s loop):
- `needed = ceil(SustainSec / IntervalSec)`.
- The first hot sample returns `arm`; the caller takes the burst snapshot.
- `needed` consecutive hot samples return `start`. A spike lasts until `needed` consecutive samples fall below `Threshold - 15`, which returns `end`.
- While the spike lasts, `ongoing` is returned every 120 s.
- State keys: `Above, Below, InSpike, SpikeStart, Peak, LastCapture, Spikes, Threshold, Needed`.

### Task 3: Embedded sampler in the app

**Files:** `openrelax.ps1`, `lib/OpenRelax.Core.ps1` (settings key `trapEnabled`), `tests/safety-contracts.ps1`, `tests/unit.ps1`.

**Changes:**
- **Paths.**
  - `$script:TrapDir` = `%APPDATA%\OpenRelax\Fotokapan` (TestMode: `OPENRELAX_TRAP_DIR`).
  - `$script:TrapLegacyDirs` = `ProgramData\OpenRelax\Fotokapan\logs` and the `ProgramData` root (empty in TestMode).
  - `Read-TrapRecords` takes `-LegacyDir [string[]]`.
- **Worker `$script:TrapSamplerCode`** (receives `$Sync`, `$Opt` with `Dir, Threshold=85, SustainSec=4, RecordCommandLines`):
  - sets its thread priority to AboveNormal;
  - writes a `monitor` record;
  - loops in 200 ms sleeps until `$Sync.TrapStop`, sampling every 2 s;
  - on `arm` takes a burst snapshot; on `start`/`ongoing` takes a second snapshot, reads the top PIDs and their parents through `Get-CimInstance Win32_Process -Filter "ProcessId=…"`, and builds and writes the record;
  - when MsMpEng is in the top 3 at ≥10 %, reads the newest Defender Operational event 1000/1001/1002 and sets `defender` to `scan` or `realtime`;
  - writes the heartbeat every 60 s;
  - on stop, writes `end` if a spike is open, then a final heartbeat.
- **Lifecycle.**
  - `Start-TrapSampler` and `Stop-TrapSampler` follow the `Start-EngineTask` pattern, with their own runspace that is not counted in `$script:Tasks`.
  - Start after the form is shown if `trapEnabled` and no legacy task is running.
  - Stop on toggle-off and in FormClosing, waiting at most 3 s.
- **State.** `Get-TrapState` returns `@{ Installed=[bool]trapEnabled; Running; Outdated=$false; Beat; Threshold; Spikes; LegacyTask; LegacyRunning }`. Running means the sampler runspace is alive and its heartbeat is younger than 180 s.
- **UI.**
  - `btnTrapInstall` becomes the on/off switch (text `btnTrapOn` / `btnTrapOff`).
  - `btnTrapRemove` becomes "Remove old background task", visible only when `LegacyTask`; it calls the existing `Start-TrapAction 'Uninstall'`.
  - The state labels gain a `trapStLegacy` text.
  - The `chkTrapCmd` hint says the change applies immediately.
- **SelfTest.** It prints `Fotokapan: enabled=… running=… legacyTask=… heartbeat=…`. verify.ps1's banner regex is unchanged.

- [ ] Safety case `'trapEnabled defaults on, older files load, non-bool rejected'`.

### Task 6: Distribution

**Files:**
- Create `.github/workflows/release.yml`, `install.ps1`, `bucket/openrelax.json`, `packaging/Update-ScoopManifest.ps1` and `tests/install-contract.ps1`.
- Wire `tests/install-contract.ps1` into `tests/verify.ps1` as a child suite.

**release.yml:**
- Triggers: `push` of tags `v*` and `workflow_dispatch` with a `tag` input.
- Runs `git archive --prefix=OpenRelax-<ver>/` and checks the required file list from verify.yml.
- Writes `SHA256SUMS`.
- Runs `gh release upload <tag> OpenRelax-<ver>.zip SHA256SUMS --clobber`; the release is created with `--verify-tag` when missing.
- Permissions: `contents: write`.

**install.ps1** — params: `-Destination` (default `%LOCALAPPDATA%\Programs\OpenRelax`), `-ZipPath` and `-ShaPath` (offline/test), `-NoShortcut`.
- Without a local zip, reads the latest release from `api.github.com/repos/mehmeterendereli/openrelax/releases/latest`.
- Downloads the zip and `SHA256SUMS` into a new temp folder and verifies the hash **before** extracting.
- Extracts to a staging folder, checks that the required files exist, then replaces the destination's program files. User data stays in `%APPDATA%` and is never touched.
- Creates a Start menu shortcut (same target and icon as `install-shortcut.ps1`) and prints every step.
- Ends with "Started? run …" instructions; it does not auto-start elevated.

**Scoop:** `bucket/openrelax.json` with `version`, `url`, `hash`, `extract_dir`, `shortcuts: [["launch.bat","OpenRelax"]]`, `checkver: github`, `autoupdate` (url and hash from `SHA256SUMS`). `packaging/Update-ScoopManifest.ps1 -Version -ZipPath` rewrites version, url and hash.

**install-contract.ps1** — uses an owned fixture; builds a zip with `git archive` and `SHA256SUMS`, then checks:
- install to the fixture destination with `-NoShortcut`: the files are present;
- a flipped byte in the zip is refused with nothing extracted;
- a zip missing `openrelax.ps1` is refused;
- the Scoop manifest parses and its `autoupdate` URL pattern matches the release asset name.

**Steps:**
- [ ] RED (install-contract fails), then implement, then GREEN.
- [ ] Commit `feat(dist): verified one-line installer, release assets and Scoop manifest`.
